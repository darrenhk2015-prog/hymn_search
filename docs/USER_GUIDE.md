# 詩歌冊搜索系統 — 使用手冊

## 1. 安裝與啟動

### 方式 A：Python 原始碼

```powershell
cd C:\python\hymn_search
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python hymn_search.py
```

### 方式 B：執行檔（免安裝 Python）

雙擊 `dist\HymnSearch.exe`（需先依 [BUILD.md](BUILD.md) 打包）。

### 資料夾準備

將詩歌檔案放在：

```
桌面\神家詩歌集new\
├── 讚美詩（新）\          ← 子資料夾 = 一本書
│   ├── xxx.pdf
│   └── xxx.docx
├── 另一本詩歌.pdf         ← 單檔也可
└── ...
```

> 若資料夾路徑不同，需修改 `hymn_search.py` 內的 `HYMN_FOLDER` 後重新執行或打包。

## 3. 三種搜尋模式

### 3.1 書本模式（預設）

1. 左側點選書冊，或在上排輸入書冊名過濾
2. **檔案關鍵字**欄可篩選檔名或 PDF 書籤標題
3. 按 **Filter** 或 Enter 套用；右側點擊檔案或書籤開啟

**技巧：** 聚焦書冊名輸入框時會清空內容，方便輸入新關鍵字；會出現下拉建議。

### 3.2 全局模式

- 輸入歌名或關鍵字，搜索**所有書冊**的 PDF 書籤與檔名
- 結果按書冊分組顯示

### 3.3 關鍵字模式

- 搜索 PDF / Word **內文**
- 首次使用建議按 **建立索引**（只需一次，之後更快）
- 勾選 **即時搜索** 可邊輸入邊找
- 檔案更新後按 **刷新索引**

## 4. 開啟檔案

| 操作 | 說明 |
|------|------|
| 點擊列表項目 | 開啟對應 Word / PDF |
| 書籤 | 開啟 PDF 並跳至該頁 |
| 僅一個結果 | 按鈕變 **Open**，Enter 直接開啟 |

**Word 自動操作：** 開啟後會自動切換適合投影的視圖（Enter → Alt+W → Alt+O）。

---

## 5. 設定（⚙ 設定）

點右上角 **⚙ 設定** 展開。

### 外觀

| 選項 | 說明 |
|------|------|
| 主題 | dark / light |
| 字體大小 | 10–18 px |

### 開啟 Word / PDF 時

| 選項 | 說明 |
|------|------|
| 顯示置頂書名提示 | 黃色浮層顯示書名（所有螢幕） |
| 提示顯示 | 1–10 秒，或 **一直顯示** |
| 提示位置 | 右下角 / 置中→右下角（含動畫） |
| 切換同步畫面 | 開啟後將延伸桌面改為複製畫面（Windows） |

**提示消失時機：**

- 達到設定秒數（若非「一直顯示」）
- **關閉 Word 或 PDF 視窗**（自動偵測）
- 取消勾選「顯示置頂書名提示」

## 6. 常見問題

### 找不到詩歌冊？

- 確認 `神家詩歌集new` 資料夾在桌面且內有 PDF/Word
- 檢查頂欄顯示的路徑是否正確

### PDF 沒跳到正確頁？

- 建議安裝 [Sumatra PDF](https://www.sumatrapdfreader.org/)（程式會優先使用）

### 關鍵字搜索很慢？

- 先按 **建立索引**，完成後再搜索

### 提示框位置不對？

- 延伸多螢幕時各螢幕都會顯示
- 若開啟「同步畫面」，切換後會自動重新定位

### 防毒軟體攔截 exe？

- PyInstaller 打包的 exe 可能被誤報，可加入信任清單
